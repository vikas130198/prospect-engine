Explain briefly (≤ 25 lines):

**What it does:** Instagram profile → business research → your approval → website audit + competitor research +
opportunity score → design selection → personalised website prototype → automated testing on 5 screen sizes →
published at your prototype address → public contact research → personalised email → saved in your Drafts.
It never sends emails or messages — you review and send everything yourself.

**Commands**
| Command | What it does |
|---|---|
| `/prospect:setup` | First-time setup and settings (re-runnable, or `/prospect:setup email` etc.) |
| `/prospect:doctor` | Check everything works |
| `/prospect:new <instagram-url>` | Start a new prospect |
| `/prospect:approve <id>` | Approve after reviewing research, and continue |
| `/prospect:reject <id>` | Reject a lead |
| `/prospect:resume <id>` | Continue where it stopped (also after usage limits) |
| `/prospect:retry <id> <stage>` | Redo one stage |
| `/prospect:list [high\|failed\|…]` | Your leads |
| `/prospect:open <id>` | One lead's details, reports and status updates |
| `/prospect:regenerate <id> <change>` | Change or regenerate a prototype |
| `/prospect:prototypes` | Disable, protect, extend, delete prototypes |
| `/prospect:library` | Your design library — drop design videos/screenshots in `design-library/inbox` |
| `/prospect:references` | Your design reference library (websites + notes) |
| `/prospect:dashboard` | Visual dashboard in the browser |

**Design:** every prototype gets engaging, timeless animations (motion presets) and is matched against the videos in
`design-library/inbox` by design fit.

**Usage tip:** On Claude Pro use Lite mode; a full prospect uses a good share of a 5-hour window. Check `/usage`.
